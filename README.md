# GNA Hotel Solutions - Hotel Offers Landing Page

Landing page desarrollada con **Vue 3** y **Vite** como ejercicio práctico de desarrollo frontend para GNA Hotel Solutions.

El proyecto reproduce una interfaz moderna para la visualización de ofertas hoteleras, siguiendo un diseño proporcionado en Figma y aplicando buenas prácticas de desarrollo frontend mediante componentes reutilizables, diseño responsive y lógica interactiva implementada con Vue.

---

## Tecnologías utilizadas

- Vue 3
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3

---

## Funcionalidades

### Sistema de filtrado dinámico

La aplicación incluye un filtro funcional que permite visualizar únicamente las ofertas pertenecientes a la categoría seleccionada.

Características:

- Actualización instantánea sin recargar la página.
- Gestión reactiva mediante Vue.
- Filtrado dinámico de contenido.
- Experiencia de usuario fluida e intuitiva.

### Arquitectura basada en componentes

La interfaz está organizada mediante componentes reutilizables:

- Header
- Hero
- About
- Filter
- Features
- Footer

### Diseño responsive

La aplicación se adapta correctamente a distintos tamaños de pantalla:

- Desktop
- Tablet
- Mobile

### Organización modular

Separación clara entre:

- Componentes
- Estilos
- Recursos gráficos
- Datos de la aplicación

## ⚙️ Instalación

Clonar el repositorio:

```bash
git clone <repository-url>
```

Acceder al directorio:

```bash
cd gna-hotel-solutions
```

Instalar dependencias:

```bash
npm install
```

---

## Desarrollo

Ejecutar el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:5173
```

---

## Build de producción

Generar una versión optimizada:

```bash
npm run build
```

Los archivos compilados se almacenarán en:

```text
dist/
```

---

## Vista previa de producción

```bash
npm run preview
```
